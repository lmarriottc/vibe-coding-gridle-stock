# \# Girdle Sales and stock tracker



\## Problem

The sales and operation teams of my girdle distribution company is loosing track of how many parts have been sold and what is the stock level for each model and size



\## Objective:

Create a simple app that allows to register each sale in an easy way and shows the updated stock level



\#Scope

* Input sales individual or by group
* Stock level maintenance by subtracting sales and adding purchases
* Stock level visuals per gridle size and model



\## Limits

* No user register or login required
* No database required
* No payment functionality
* No advanced mobile design
